# 💰 Pocket Ledger — ربات تلگرام حسابدار شخصی

ربات تلگرامی برای ثبت حساب‌های بانکی، موجودی‌ها و تراکنش‌ها با **زبان محاوره‌ی فارسی** و **پیامک بانک**، همراه با گزارش‌های دوره‌ای، نمودار و تحلیل هوشمند با **Gemini**.

> A personal-finance Telegram bot for Persian speakers: log transactions in plain Persian or by forwarding bank SMS, get Jalali-calendar reports, charts and AI (Gemini) analysis.

## ✨ امکانات

- **ثبت با متن آزاد**: «۸۵ هزار ناهار با کارت ملت»، «حقوق ۳۵ میلیون واریز شد»، «۲ میلیون از ملت به سامان منتقل کردم»
- **پیامک بانک**: پیامک را فوروارد یا کپی کنید؛ مبلغ (ریال ← تومان)، حساب و مانده خوانده می‌شود
- **تطبیق موجودی**: اگر مانده‌ی پیامک با حساب ربات فرق کند، اختلاف را نشان می‌دهد و با یک دکمه اصلاح می‌کند
- **کارت تأیید** قبل از هر ثبت، با امکان تغییر حساب و دسته‌بندی
- **چند حساب بانکی** با موجودی لحظه‌ای و انتقال بین حساب‌ها
- **طلب و بدهی**: «۵ میلیون به علی قرض دادم» / «علی ۲ میلیونش رو پس داد»
- **اقساط و پرداخت‌های تکراری** با یادآوری خودکار و دکمه‌ی «پرداخت شد»
- **گزارش** امروز / هفته / ماه / ماه قبل / سال (تقویم شمسی، هفته از شنبه) با مقایسه با دوره‌ی قبل
- **نمودار** دایره‌ای دسته‌بندی‌ها و نمودار روند ۶ ماهه
- **تحلیل و توصیه‌ی هوشمند** با Gemini
- **ارسال خودکار**: خلاصه‌ی شبانه، گزارش هفتگی (جمعه‌ها) و گزارش + تحلیل ماهانه (اول هر ماه شمسی)
- **خروجی اکسل** راست‌به‌چپ با تاریخ شمسی
- فقط صاحب ربات به آن دسترسی دارد

## 🚀 نصب و اجرا (ویندوز)

۱. پایتون ۳.۱۱ یا جدیدتر نصب باشد.
۲. ربات را در [@BotFather](https://t.me/BotFather) بسازید و توکن را بگیرید.
۳. کلید Gemini را از [Google AI Studio](https://aistudio.google.com/apikey) بگیرید.
۴. فایل `.env.example` را به `.env` کپی و پر کنید:

```bash
copy .env.example .env
```

۵. اجرا (بار اول محیط مجازی و کتابخانه‌ها را خودش نصب می‌کند):

```bash
start.bat
```

۶. در تلگرام به ربات `/start` بدهید. اگر `OWNER_ID` را خالی گذاشته باشید، ربات آیدی عددی شما را می‌گوید؛ آن را در `.env` بگذارید و دوباره اجرا کنید.

**اجرای خودکار با روشن شدن سرور** (PowerShell با دسترسی Administrator):

```bash
powershell -ExecutionPolicy Bypass -File install_autostart.ps1
```

لاگ‌ها در `logs\bot.log` و دیتابیس در `data\ledger.db` ذخیره می‌شوند. از پوشه‌ی `data` نسخه‌ی پشتیبان نگه دارید.

### لینوکس / اجرای دستی

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python main.py
```

### 🌐 نکته برای سرورهای داخل ایران

تلگرام و Gemini از IP ایران در دسترس نیستند. در این حالت در `.env` مقدار `TELEGRAM_PROXY` (برای تلگرام) و `HTTPS_PROXY` (برای Gemini) را تنظیم کنید، یا ربات را روی سرور خارج اجرا کنید. بدون Gemini ربات با یک تحلیل‌گر ساده کار می‌کند ولی دقت کمتری دارد.

## 💬 دستورها

| دستور | کار |
|---|---|
| `/balance` | موجودی همه‌ی حساب‌ها، طلب/بدهی و دارایی خالص |
| `/today` `/week` `/month` | گزارش دوره |
| `/report` | انتخاب دوره‌ی گزارش |
| `/analyze` | تحلیل هوشمند |
| `/last` | ۱۰ تراکنش آخر با امکان حذف |
| `/undo` | حذف آخرین تراکنش |
| `/accounts` `/addaccount` | مدیریت حساب‌ها |
| `/debts` | طلب و بدهی |
| `/recurring` | اقساط و پرداخت‌های تکراری |
| `/export` | خروجی اکسل |
